IRIS Relay Lite

Served by IRIS from the iris-relay IPM package. Reads messages.log and its rotations through /api/relay and runs vector similarity search inside IRIS. No Node.js or Python server. The full IRIS Relay UI (management, tasks, audit, REST explorer and handover) is at index.html, served by IRIS from the same package.

Sign in

Needs %Admin_Operate:U. Credentials stay in this page's memory only and go to IRIS as HTTP Basic on each request, so the page sends them only over HTTPS or on this machine (localhost, 127.0.0.1, [::1]).
